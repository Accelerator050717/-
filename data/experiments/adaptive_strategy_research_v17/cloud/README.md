参数名为 `research_mode` 和 `cost_bps`，不是旧脚本的 `mode`。

|research_mode|规则|
|---|---|
|`eq`|当期持续流动性前100等权|
|`mom20`|同池20交易日价格动量前10|
|`trend63`|63日收益剔除最近20日前10|
|`ridge`|年度 StandardScaler + Ridge(alpha=100, solver=svd) 前10|
|`trend63_risk`|trend63 加固定 SPY200均线45%/90%仓位规则|
|`ridge_risk`|ridge 加同一仓位规则|
|`spy`|同执行和费用口径的90% SPY对照|

`cost_bps` 仅允许 `10`、`20`。先完成预登记的七个10bp配置，再按 PLAN 的规则最多选择一个候选、eq、spy运行20bp。不能看到结果后继续添加阈值或挑选月份。

## 时间和口径

引擎从2018-12-01开始，12月仅建立成交额窗口；2019—2021收集当时动态股票池的月度训练样本且不交易。实际资金评估严格为2022—2023，初始100,000美元，整股、90%常规仓位、零现金利息、月度决定、下一开盘减仓、再下一开盘增仓。

当时 Morningstar 覆盖的普通股保留稳定 SID；原始价格>$5，最近20个完整已知交易日 DollarVolume 中位数前100。低价日也保留在历史流动性窗口，资格检查使用当时最新价格。停牌/缺失导致窗口不连续时明确计数，不补造量价，也不按未来存续筛选。

信号使用127个连续 SplitAdjusted 收盘价。mom20、trend63、Ridge 共用当时特征完整的范围；eq仍保留不满足长特征历史的当期池成员，因此“特征历史不足”必须报告。分红由 LEAN 现金事件记账，不是实际支付日回放。

每年只拟合一次 Ridge。观察日期和标签结束时间均严格早于部署年1月1日；一月决策时刚刚得到的跨年标签不进入当年模型。缺少终点的退市/缺价标签记录为未解决，不填0；可计算标签是在已观察终点证券之间的名次，不能称为完整生命周期无偏样本。

**不要直接采用 Overview 年化收益作本轮比较**：平台可能把三年多现金暖机期算入年化。使用普通日志 `V17_SUMMARY` 的2022—2023指标及 `v17_month_YYYY-MM` 核对年度、月度结果。账户高水位在2022—2023连续保存，不因2023模型更新而重置。

## 保存与只读核对

原始供应商行情和 Fundamental 记录留在允许的云环境。本轮保存完整模型参数、月末资金净值、预测面板哈希、主要证券损益及问题摘要等派生材料；完整预测分数及逐证券损益未全部归档，不输出 OHLCV 面板。

实际运行证实 RuntimeStats 每值仅200字符、最多50个自定义字段。原revision02较大字段和后续字段被截断/忽略；不能靠哈希反推内容。输出修订最多45字段：24个月度资金值、必要统计和模型简要身份。完整 scaler 均值、尺度、Ridge系数和截距写入普通拟合日志，全部本代码日志自限9KB，为平台10KB额度留出引擎空间。三个普通账户图显示日频权益、持仓及现金；本轮官方Download Results路径被浏览器工具安全规则阻断，下载未确认，停止尝试且不绕过。完整预测向量不能在当前Free输出额度中归档；只保存身份哈希及冻结复算源码，不能称作已保留完整向量。

从可见 RuntimeStats 捕获 **原始单元格字符串**，保存为：

```json
{"runtime_statistics":{"v17_month_2022-01":"[\"2022-01-31\",100000,0,100000,0]"},"run_identity":{"project_id":37249270,"backtest_id":"实际ID"}}
```

以上是输入格式示意，不是真实结果。不要先在 JavaScript 中解析再重新序列化内部 JSON，以免把 `1.0` 转成 `1` 破坏原始哈希。

```powershell
.venv\Scripts\python.exe tools/summarize_v17_cloud.py --input 路径\runtime_capture.json --logs 路径\logs.json --output 路径\verified
```

日志文件采用实际DOM捕获格式 `{"log_rows":[["时间戳","V17_SUMMARY {...}"], ...]}`，原始字符串保持完整。核对器保留 SUMMARY、FITS 和已有派生材料，检查月末现金、年度连乘、两年年化、费用、模型哈希和成熟时间边界；不会给缺失的完整预测/证券损益写一个空CSV冒充完成。若从官方图表下载取得完整日频记录，可以在输入增加 `daily_nav` 的日期/权益/持仓/现金数组，独立重算回撤、波动和平均仓位；必须核对501行及时间对齐，不能假定平台未抽样。单凭月度净值不能独立重算日频最大回撤。

浏览器中断后，先根据项目 Backtests 列表和已记录 ID 查询原运行是否仍在运行/已完成，保存其结果，再决定是否需要恢复。不要因页面超时立即启动同一配置的重复回测。只有完整数据门槛、账本门槛及原始输出核对通过，才把该运行计入有效比较；本地测试不等于真实云回测通过。

操作注解中的 `mode`/`cost_bps` 也会与实际生成摘要核对。若不一致，验证失败并保留真实摘要，不根据意图给产物贴标签。例：`runs/attempt12_completed_capture.json` 意图SPY20、实际eq20；`repeats/attempt12_actual_eq20/VERIFICATION.json` 仅此身份检查失败。正确恢复是核对项目已保存参数/构建及运行初始V17_IDENTITY，再执行仍缺少的配置，不修改旧捕获或覆盖canonical结果。
